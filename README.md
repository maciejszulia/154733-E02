# 154733-E02

An object-oriented programming exam in Java: three tasks on generic methods, collections and files.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2022 (first commit on 8 February 2022, last commit on 14 February 2022).

## Contents

- `egzamin/src/Z1/`: `ArrayUtil.isSorted`, a generic check whether an array of `Comparable` values is sorted, with a demo on integers and `LocalTime` values.
- `egzamin/src/Z2/`: a generic method that prints the elements of any `Iterable`, with a demo on `LinkedList`, `TreeSet` and `ArrayList`.
- `egzamin/src/Z3/`: a method that returns the subdirectories of a directory (`File::isDirectory`).
- `.idea/`, `egzamin/egzamin.iml`: IntelliJ IDEA project files.

## Running

The code needs a Java compiler (JDK), which this machine does not have, so I did not run it in November 2026.
